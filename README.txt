J.P. MACHINE TOOLS — THE DRY-SYRUP LINE, TAKE IT APART
======================================================

Open index.html (the configurator). Pick a station, pick a model, and step
into that machine's full-scale teardown. jpmt-line.html runs all six
stations end to end at the line rate.

Everything here is offline and self-contained: one file per page, no
internet needed. All machine numbers are verbatim from www.jpmtglobal.com;
anything modelled (dimensions the site does not publish) is flagged in each
page's ledger and in the jpmt/README.md of the build workspace.

Built as a pitch artifact. Contact: see www.jpmtglobal.com.
